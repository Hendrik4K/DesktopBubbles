# Many shortcuts. One bubble. ✨

Your Windows desktop deserves app folders. Put your launchers, tools and favorite shortcuts into a glass bubble. Click to open. Pick your app. Enjoy the extra space.

**Viele Launcher. Eine Bubble. Mehr Platz auf deinem Desktop.** 🚀

![DesktopBubbles before and after](https://raw.githubusercontent.com/Hendrik4K/DesktopBubbles/v1.6.0/docs/screenshots/desktopbubbles-before-after.gif)

## New: hold, wiggle, swap

Hold an icon in an open folder for about half a second. The icons start to wiggle. Drop the grabbed icon onto another and **exactly those two swap places**. The order is saved and the desktop miniature updates too. Press Esc or click an empty area to finish sorting. A short click still launches the app.

## Make room for your desktop

- Add shortcuts with drag & drop; move them between bubbles or return them to the desktop.
- Customize miniature and folder size, transparency, colors and rounded corners. Light and dark mode have their own editable colors and control opacity.
- Remove broken entries without needing a working target. Programs and saved shortcut copies stay untouched.
- Keep your groups local. No account, telemetry or automatic uploads. Optional resource tracking starts only when you choose.

## Download and run

Download **DesktopBubbles-win-x64-v1.6.0.zip**, extract the entire archive and run **DesktopBubbles.exe**. Windows 11 x64; the .NET desktop runtime is included. No administrator rights needed. The package is unsigned and portable, with no installer or automatic updater.

**Updating:** quit the old app through its tray menu first. Back up and carry over the full active data folder shown by **Einstellungen → Datenordner öffnen**. If you used the separate 1.6 preview, use its data folder to keep changes made there. Do not run both versions together. Schema remains 6. Public ZIPs contain no user data.

Source ZIP, MIT license, runtime notices and SHA-256 sidecars are included. Desktop integration remains experimental; platform test coverage and limitations are documented in the [test report](https://github.com/Hendrik4K/DesktopBubbles/blob/v1.6.0/docs/TESTS.md).

**Verified:** 122 core checks and 124 native UI/integration checks passed. The native run uses AppearanceOnly mode; desktop click-surface/MinimizeAll checks and physical mouse coverage are outside that run.
