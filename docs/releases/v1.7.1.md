# DesktopBubbles 1.7.1 — Ein neuer Look für deine Bubbles 🫧

DesktopBubbles bekommt ein neues Gesicht: schillernde Regenbogen-Seifenblasen ersetzen das bisherige Kachel-Logo. Das neue Symbol begleitet dich in der App, auf der Taskleiste, im Tray und im Installer.

- Transparente Icons in neun Größen von 16 bis 256 Pixeln.
- Das Fensterlogo verwendet das unveränderte, vom Projektinhaber bereitgestellte Motiv.
- Deine Gruppen, Einstellungen und Verknüpfungen verwenden weiterhin dasselbe Datenformat. Dieses Update ändert die Darstellung des Logos, nicht die Bedienung.

## Download und Update

**DesktopBubbles-Setup-1.7.1.exe** installiert für dein Windows-Benutzerkonto und legt den Startmenüeintrag an. Beende eine laufende Ausgabe vorher über das Tray-Menü → **Beenden**. Der Installer sichert vorhandene Daten am vorgesehenen Programmort vor dem Update.

Alternativ: **DesktopBubbles-win-x64-v1.7.1.zip** vollständig entpacken. Bei einer bisherigen portablen Ausgabe zunächst den aktiven Datenordner sichern und die [Hinweise zur Datenübernahme](https://github.com/Hendrik4K/DesktopBubbles/blob/v1.7.1/docs/STARTUP.md) beachten. Unterschiedliche Datenstände werden nicht automatisch zusammengeführt.

Quellcode: **DesktopBubbles-Source-v1.7.1.zip**. Für alle drei Downloads liegen SHA-256-Prüfsummen bei.

Windows 11 x64. Kostenlos und quelloffen unter MIT. Setup und App sind weiterhin unsigniert; Windows kann einen Hinweis auf einen unbekannten Herausgeber anzeigen. Die Desktop-Anbindung bleibt experimentell. Es gibt keinen automatischen Updater.
