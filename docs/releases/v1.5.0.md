# DesktopBubbles 1.5.0

**App folders for your Windows 11 desktop.** Put your shortcuts into a small desktop bubble, open it with one click, and choose the app you want to launch.

## Download

Download **DesktopBubbles-win-x64-v1.5.0.zip**, extract the entire archive into a writable folder and run **DesktopBubbles.exe**. The .NET desktop runtime is included; no administrator account is required. This is an unsigned portable x64 app with no installer or automatic updater.

## What's new

- A cleaner interface with full-width Miniatur / Ordner tabs, aligned group thumbnails and settings beside resource tracking.
- Shared thumbnail and folder sizes, separate global transparency up to 100%, and proportional rounded corners.
- Optional color linking across all groups, a live inline color editor and separate customizable light/dark palettes.
- Live folder preview with 1:3 / 1:1 switching.
- Simpler menus, a clearer **Zurück zum Desktop** action and a minimal tray menu with version and repository link.
- New smoked-glass app icon, embedded at nine resolutions.

Closing the management window leaves your bubbles running. Double-click the tray icon to reopen it; choose Beenden to quit.

## Upgrading

Quit the previous app from its tray menu first. Extract into a new folder and copy your **entire previous data folder**, or import a .bubbles backup. Personal data is excluded from release archives. Older configurations migrate to schema 6; do not reopen migrated data with an older app version. Full instructions: [README](https://github.com/Hendrik4K/DesktopBubbles/blob/v1.5.0/README.md).

## Validation and feedback

**104 core checks and 116 full native Windows checks passed** on Windows 10.0.26300.0 x64 with .NET 8.0.32. The desktop integration remains experimental. Physical Explorer drag-and-drop, mixed DPI / multiple monitors and further Windows configurations still need community testing. [Test scope](https://github.com/Hendrik4K/DesktopBubbles/blob/v1.5.0/docs/TESTS.md).

Source code is available under MIT. Runtime license notices are included. SHA-256 sidecars accompany both ZIP assets. [Report an issue](https://github.com/Hendrik4K/DesktopBubbles/issues) with your Windows version, scaling and reproduction steps; review logs for personal paths before sharing.
