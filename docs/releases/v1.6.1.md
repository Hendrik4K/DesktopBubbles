# DesktopBubbles 1.6.1 — Startup uses the right app and data

Fixes a misleading startup checkbox when switching between portable copies, previews and an installed version.

Previously, **Mit Windows starten** looked enabled whenever any DesktopBubbles startup entry existed. Windows could still be pointing to an older executable and a different data folder. That could look like groups or settings had reset, even though the newer collection was still present in the other folder.

## What changed

- The checkbox now matches the actual executable, full data directory and portable mode.
- A registration for another copy is shown as inactive for the current copy. A tooltip explains how to select the desired app and data folder.
- Only explicitly enabling the option changes the startup registration. Opening settings does not change it.
- Startup command quoting also handles a drive root used as a data folder. Paths are compared case-insensitively; command-line switches must match the options the app actually recognizes.
- Includes an [upgrade and data-folder guide](https://github.com/Hendrik4K/DesktopBubbles/blob/v1.6.1/docs/STARTUP.md). Schema remains 6; separate collections are not automatically merged.

## Updating / Aktualisieren

1. In the copy containing your **latest groups**, open **Einstellungen → Datenordner öffnen**.
2. Quit all DesktopBubbles copies through their tray menus and back up the **entire active data folder**.
3. Extract **DesktopBubbles-win-x64-v1.6.1.zip** to a stable, writable location. Carry over the full data folder or select it with `--data-dir`. Internal shortcuts and recovery journals belong with the configuration.
4. Start the new copy and verify your groups. Enable **Mit Windows starten** there if you want this copy and its current data folder to start with Windows.

**Deutsch:** Der Patch korrigiert die Autostart-Zuordnung. Wenn eine andere Ausgabe einen älteren Stand zeigt, zuerst die neuere Datensammlung finden und vollständig sichern. Die neue Version wählt nicht automatisch zwischen unterschiedlichen Speicherständen.

**Validation:** 130 core checks and 124 native UI/integration checks passed in AppearanceOnly mode. Startup command checks do not modify the real registry. A full Windows reboot/login remains outside this automated test scope. [Test details](https://github.com/Hendrik4K/DesktopBubbles/blob/v1.6.1/docs/TESTS.md).
