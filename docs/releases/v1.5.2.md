# DesktopBubbles 1.5.2

Fixes settings and entry deletion failing when portable data sits in a protected folder such as Program Files.

- Detects unwritable storage before loading. Existing groups, settings, shortcut copies and recovery history are verified and copied into a writable per-user profile. The original remains untouched; subsequent starts keep the newer copy.
- Keeps data from different source folders separate. **Datenordner öffnen** opens the active storage. Before moving/upgrading, use that active folder for backups or --data-dir.
- Uses unique temporary state filenames, avoiding stale or locked groups.json.tmp files.
- Adds **Deckkraft** to the light/dark color editor. Background opacity is stored separately per mode, with live preview, Apply and Cancel. Brightness, text and app/bubble transparency remain independent.

**117 core checks and 124 full native Windows checks passed**, including read-only migration, deletion persistence and mode opacity.

Download DesktopBubbles-win-x64-v1.5.2.zip and extract the entire archive. No administrator rights are needed to run the app. Quit the previous version through its tray menu before upgrading and preserve the full active data folder. Users of older unwritable versions should export any still-unsaved changes before closing them; 1.5.2 can migrate saved files but cannot read another process's unsaved memory.

The unsigned portable x64 package includes the .NET runtime and license notices. Personal data is excluded. Source ZIP and SHA-256 sidecars are included. Schema remains 6.
