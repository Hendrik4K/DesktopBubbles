# DesktopBubbles 1.5.1

This patch adds **Aus Gruppe löschen** (remove from group) to the app-icon context menu, alongside Starten and Zurück zum Desktop.

Broken entries can now be removed even when their shortcut, target or recovery metadata is missing. This action removes only the selected group entry: it does not restore anything to the desktop, delete files/programs or modify other groups. Internal recovery copies remain intact. If saving fails, the entry is restored to its original list position.

**108 core checks and 118 full native Windows checks passed**, including invoking the actual context-menu action for a missing target and verifying persistence. [Test report](https://github.com/Hendrik4K/DesktopBubbles/blob/v1.5.1/docs/TESTS.md).

Download DesktopBubbles-win-x64-v1.5.1.zip, extract it into a writable folder and run DesktopBubbles.exe. Quit the old app through its tray menu before upgrading; copy the complete data folder to preserve your groups. The release ZIP contains no personal data. Schema remains 6. The unsigned portable x64 package includes the .NET runtime and license notices. Source ZIP and SHA-256 sidecars are provided.
